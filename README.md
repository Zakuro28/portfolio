# Zacc Bandahala — portfolio

Live at https://zacc-portfolio.vercel.app

Web developer and QA tester from the Philippines. The site shows five live projects (Kit, Pitaka, Skyfall, Zacc Websites, Pager), work experience, skills and contact details.

## Run it

```bash
npm install
npm run dev
```

Built with React, TypeScript, Vite, Tailwind CSS, Motion and Lucide icons.
